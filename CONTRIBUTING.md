# Contributing

Use Node.js 22 and Python 3. Run `npm ci`, `npm run check`, `npm run spk`, and `npm run test:spk`. Docker verification runs in Linux CI. Core tests must stay independent of live DSM/OpenAI services and use temporary directories. Integration tests use the official MCP SDK client. Keep source changes in core transport-independent, enforce authorization before file access, and update the threat model when introducing a new data path.

Include concrete validation results and limits in PRs. New formats need strict size limits and parser threat analysis. New auth/network features need primary documentation and explicit audience, scope and revocation semantics. Never commit credentials, local config, NAS documents or personally identifying test data. Build artifacts are generated by CI; keep them out of Git.

The project is independent of Synology and OpenAI; use original artwork and avoid implying official approval. OpenAI integration references are date-stamped in `docs/openai-integration.md`.
