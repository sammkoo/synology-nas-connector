Synology NAS Connector

The package starts with no folders exposed.

Choose folders

Grant the internal package account SynologyNASConnector read-only permission to selected shares. Add those folders to the private /var/packages/SynologyNASConnector/var/config.json, then restart from Package Center.

Open the service dashboard

The connector listens on NAS loopback port 8787. Forward it to your computer using your existing authorized SSH access:

ssh -N -L 8787:127.0.0.1:8787 your-admin@your-nas

Then open the local dashboard. Enter the access token only there. The private token lives in the package var/token file.

For ongoing use, configure a DSM HTTPS reverse proxy and the connector's exact hostname/origin allowlists. See the repository installation guide. This static DSM page contains no credentials or live status.
